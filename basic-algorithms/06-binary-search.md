## Problem: Binary Search (Easy)
**Link:**(https://leetcode.com/problems/binary-search/)

### Approach
Used a two-pointer binary search technique by repeatedly dividing the sorted search interval in half.

### Complexity
- Time: $O(\log n)$
- Space: $O(1)$

### Notes
Handled edge cases where the target is not in the array or the array has a single element.
