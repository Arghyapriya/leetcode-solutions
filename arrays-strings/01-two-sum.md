## Problem: Two Sum (Easy)
**Link:** (https://leetcode.com/problems/two-sum/)

### Approach
Used a hash map or single-pass traversal to find the complement of each element. This allows us to check if the required target value exists in constant time, achieving an optimal $O(n)$ solution.

### Complexity
- Time: $O(n)$
- Space: $O(n)$

### Notes
Learned how to handle edge cases like negative numbers and avoiding duplicate element usage.This is the brute-force approach. A hash map can be used next time to optimize the time complexity to $O(n)$.
